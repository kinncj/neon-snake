# i18n

All user-facing text is translatable (ADR 0004). Three locales ship:
**en** (complete, the fallback), **ja**, **es**.

## Selecting a locale

1. `?lang=en|ja|es` in the URL wins.
2. Otherwise the first `navigator.languages` entry whose base tag is
   shipped (`es-MX` → `es`).
3. Otherwise English.

`window.__snake.setLocale("ja")` switches at runtime (the debug surface the
e2e tests use); every bound surface re-renders in place and `<html lang>`
follows.

## Where strings live

- `app/adapters/i18n/strings.ts` — the typed catalog. `en` is required to
  be complete at the type level; a unit test requires `ja` and `es` to
  cover every key with the same `{placeholders}`.
- `app/adapters/i18n/index.ts` — `t(key, params)`, `tIn(locale, key)`,
  `setLocale`, `onLocaleChange`, `detectLocale`, and `bindDom(root)` for
  static DOM (`data-i18n="key"`, optionally `data-i18n-attr="aria-label,title"`).

## Surfaces

| Surface | How it translates |
|---|---|
| HUD labels (Score / Best / Level / combo / MAX) | `hud.ts` re-renders on `onLocaleChange` |
| Title, pause and gameover overlays (incl. death cause) | `overlays.ts` re-renders on change |
| Level-up banner | formatted at show time |
| Settings panel (title, four toggles, on/off, close) | `settings.ts` re-renders on change |
| Mute button `aria-label`/`title` | `data-i18n` binding |
| D-pad button `aria-label`s | `data-i18n` binding |

Adding a locale: add it to `LOCALES`, add its block to `STRINGS`, run
`make test` (the completeness test will list any missing key).
