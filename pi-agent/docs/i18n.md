# i18n — internationalization

The game ships with `en`, `ja`, `es`. All user-facing strings resolve
through `app/adapters/i18n/` — never hardcode UI text.

## How it works

```
strings.ts (data)                     index.ts (logic)
┌─────────────────────────┐           ┌──────────────────────────────┐
│ MessageKey (union)      │◄──────────│ t(locale, key, params?)      │
│ Catalog per locale      │           │   locale value → en fallback │
│ PARAMS (placeholders)   │           │ {name} interpolation         │
└─────────────────────────┘           │ memoised for param-free keys │
                                      │ localeFromTag / detectLocale │
                                      └──────────────────────────────┘
```

- **Domain never sees strings.** The engine and replay logs are
  locale-agnostic; i18n is a presentation adapter.
- **English is the fallback**: any missing value in another locale resolves
  to English at runtime; CI (completeness test) makes sure that never
  happens.
- **Budget**: static labels are resolved once (memoised); per-event
  interpolation (level-up banner) is the only allocating path, and it is
  rare.

## Adding a string

1. Add the key to `MessageKey` in `strings.ts`.
2. Add its value to `CATALOGS.en`.
3. If it contains `{placeholder}`, add the placeholder name to `PARAMS`.
4. Add the translation to every other locale (`ja`, `es`).
5. Use it: `t(locale, "your.key", { n: 3 })`.

The unit tests (catalog completeness, placeholder contract) run on every
build and catch steps 2–4 being skipped.

## Adding a locale

1. Add the code to the `Locale` union and `SUPPORTED`.
2. Add a complete `Catalog` to `CATALOGS` (every key from `en`).
3. Done — `localeFromTag` picks it up automatically for BCP-47 matching.

## Locale selection

1. User choice (persisted — wired in step 19's HUD).
2. `navigator.language` via `detectLocale` (exact locale → 2-letter prefix
   → `en`).

RTL, pluralization, and gender forms are intentionally out of scope (ADR
0004); the three shipped locales need none of them.
